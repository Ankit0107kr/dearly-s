# Dearly's — conventions

Applies to both `Backend/` and `Frontend/`.

## Code style

- **Write the minimum code that does the job.** No speculative abstractions, options, or helpers that have one caller. Prefer extending what exists over adding a new layer.
- **Comments: 2 lines maximum, and only when necessary.** Comment the non-obvious *why* — a constraint, a gotcha, a reason the obvious approach fails. Never restate what the code says. Most code needs no comment.
